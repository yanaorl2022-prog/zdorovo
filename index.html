🎓 ІНФОГРАФІКА ДЛЯ ВИПУСКНИКА

Як вижити під час іспитів

4 правила, які рятують тіло, мозок і нерви

🪑
Блок 1

Стоп-сидяча пастка

2 швидкі вправи під час 2-годинної підготовки за комп'ютером:

  • 1.«Ні-ні» для шиї: повільно нахили голову вліво-вправо, вперед-назад (30 сек).
  • 2.«20-20-20» для очей: кожні 20 хв дивись 20 сек на об'єкт за 20 футтів (6 м).
🥗
Блок 2

Мозок на максимумі

Корисні перекуси замість швидких вуглеводів:

  • ✓Горіхи + ягоди — омега-3 для концентрації.
  • ✓Йогурт + банан — повільна енергія без стрибків цукру.
  • ✓Вода з лимоном — замість енергетика.
📵
Блок 3

Інформаційний детокс

Налаштуй гаджети та простір, щоб мозок відпочивав:

  • 1.Режим «Не турбувати» під час навчання — тільки важливі дзвінки.
  • 2.Провітрювання + рослина на столі — кисень для мозку.
  • 3.Перерва 5 хв без екранів кожні 45 хв роботи.
🌙
Блок 4

Формула якісного сну

Золоте правило: що робити за 60 хв до ліжка:

  • 23:00Вимкнути всі екрани, приглушити світло.
  • 23:15Теплий душ або чай без кофеїну.
  • 23:3010 хв читання паперової книги або дихальна вправа 4-7-8.
  • 23:45Відбій. 7.5–8 годин сну = продуктивний ранок.
✨

Пам'ятай: ти — не робот!

Твоє здоров'я — фундамент успіху на іспитах, а не перешкода.

🎨

Лаконічність

Без «води» — тільки конкретні дії та поради.

📝

Чіткість

Не більше 3–4 речень на один блок.

🔥

Яскравість

Заголовки, іконки, контраст — щоб чіпляло око.
